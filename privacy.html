JobSearcher Privacy Policy

Last updated: October 28, 2026

JobSearcher is a personal tool used only by its developer, Shabbir Talib. It is not offered to the public, and no one other than the developer signs in to it. This policy describes how the tool handles the developer's own Google account data.

What the app accesses

With the developer's permission, the app uses the Gmail API (scope: gmail.modify) to:

  • search for and read job-alert emails from one specific sender, mihailo@migratemate.co;
  • add a Gmail label to emails it has already processed, so that they are not processed twice;
  • send one summary email to the developer's own address.

The app does not read, change or delete any other emails.

How the data is used

The text of those job-alert emails and of the linked job postings is sent to an AI model provider through OpenRouter (openrouter.ai) in order to rate each job against the developer's resume and to draft a tailored resume. The results are emailed back to the developer.

Storage and sharing

The app has no database and keeps no copy of emails. It runs on the developer's own computer, and the sign-in credentials are kept only in a private configuration file on that computer. Data is not sold, shared with advertisers, or used for any purpose other than the one described above. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be removed at any time at myaccount.google.com/permissions. The label added to processed emails can be deleted from Gmail settings.
